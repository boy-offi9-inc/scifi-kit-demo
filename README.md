# SciFiKit Demo

Demo app for [SciFiKit](https://github.com/Boy-Offi9/scifi-ui-kit): one screen in XML Views, one in Jetpack Compose.

It pulls the library from JitPack, the same way any app would (`app/build.gradle.kts`):

```kotlin
implementation("com.github.Boy-Offi9.scifi-ui-kit:scifikit:main-SNAPSHOT")
```

## Get the APK

Every push builds a debug APK. Open the latest run in the **Actions** tab and download
`scifikit-demo-debug` from **Artifacts**.
